# Дизайн-дайджест

Статический минисайт: главная-витрина + страницы отдельных задач. Никакой сборки — просто HTML/CSS, редактируется руками и заливается в GitHub.

## Структура

```
index.html              — главная витрина (RU)
en/index.html           — главная витрина (EN), зеркало index.html
styles/tokens.css        — цвета и типографика (токены из Figma)
styles/main.css          — вёрстка и компоненты
tasks/template/          — шаблон страницы задачи (RU)
  index.html
  tile-cover.jpg         — обложка для плитки на главной (плейсхолдер)
  cover.jpg              — обложка на странице задачи, необязательна (плейсхолдер)
  gallery-1.jpg          — картинка в галерее, с подписью (плейсхолдер)
  gallery-2.jpg          — картинка в галерее, с подписью (плейсхолдер)
tasks/<название-задачи>/         — страница задачи (RU)
en/tasks/<название-задачи>/      — та же страница задачи (EN), зеркало RU-версии
```

Обложка для плитки на главной (`tile-cover.jpg`) и обложка на странице самой задачи (`cover.jpg`) — это разные файлы, можно поставить разные картинки. Обложка на странице задачи не обязательна: если она не нужна, просто удалите `<img class="cover-image" src="cover.jpg" alt="" />` из `index.html` задачи. У обложек подписей нет — подписи есть только у картинок в галерее (`gallery-*.jpg`, обёрнуты в `.cover-block` с `.cover-block__caption`).

Картинки (`tile-cover.jpg`, `cover.jpg`, `gallery-*.jpg` и т.д.) не дублируются в `en/` — EN-страницы ссылаются на те же файлы в `tasks/<название-задачи>/` через относительный путь на уровень выше (`../../../tasks/<название-задачи>/…`). Если меняете картинку, достаточно перезаписать файл один раз — обновится и RU, и EN.

## Как добавить новую задачу

1. Скопируйте папку `tasks/template` в `tasks/<название-задачи>` (латиницей, без пробелов, например `tasks/onboarding-redesign`).
2. В новой папке откройте `index.html` и замените текст: заголовок, подписи под галерейными картинками («Описание картинки»), «Контекст», пункты списка, цифры и подписи в «Результат», ссылку в «Ссылка →».
3. Замените картинки `tile-cover.jpg` (обложка плитки на главной), `cover.jpg` (обложка на странице задачи — можно удалить вместе с `<img>`, если не нужна), `gallery-1.jpg`, `gallery-2.jpg` на свои — просто перезапишите файлы с теми же именами (или подставьте свои имена и поправьте `src` в HTML).
4. Ссылку «Следующая задача →» поправьте на путь к следующей по порядку задаче: `../<следующая-задача>/index.html`.
5. На [index.html](index.html) найдите нужную карточку проекта и добавьте плитку задачи в `.task-grid` (скопируйте один блок `<a class="task-tile">…</a>` и поменяйте текст, картинку и `href` на `tasks/<название-задачи>/index.html`).
6. Добавьте английскую версию: создайте `en/tasks/<название-задачи>/index.html` по образцу любой из существующих EN-страниц (например `en/tasks/tariffs/index.html`) — переведите текст, но ссылки на картинки оставьте указывающими на оригиналы в `tasks/<название-задачи>/` (через `../../../tasks/<название-задачи>/…`, без дублирования файлов). Не забудьте добавить плитку в `en/index.html` и переключатель `.lang-switch` на обеих страницах (RU → EN и EN → RU).
7. Закоммитьте и запушьте изменения в GitHub.

## Как добавить новый проект на главную

Скопируйте блок нужного размера карточки (`project-card--big`, `--medium`, `--small` или `--xs`) в соответствующей секции `index.html` и замените текст. Секции (`СЕКЦИЯ 1/2/3`) — это просто визуальные группы, добавляйте карточки в любую из них. Не забудьте повторить то же самое в `en/index.html`.

## Английская версия и переключатель языка

- Английская версия сайта лежит в `en/` и зеркалирует структуру RU-версии 1:1: `en/index.html` ↔ `index.html`, `en/tasks/<задача>/index.html` ↔ `tasks/<задача>/index.html`.
- CSS, шрифты и картинки — общие, EN-страницы просто ссылаются на них с дополнительным `../` в пути (они лежат на один уровень глубже).
- На каждой странице есть блок `.lang-switch` (RU / EN) в правом верхнем углу — при добавлении новой страницы копируйте разметку с соседней страницы и поправьте `href` на путь к точному аналогу на другом языке.
- Бонус-кейс «Вход в команду и построение доверия на удалёнке» не опубликован ни на сайте, ни в EN-версии — это осознанное решение, синхронизировать его не нужно.

## Публикация (GitHub Pages)

Эта папка (`docs/`) — это и есть корень сайта. Всё, что лежит рядом с ней в `не для GitHub/`, в репозиторий не попадает (см. `.gitignore` в корне репозитория).

1. Создайте репозиторий на GitHub и запушьте туда весь репозиторий (папку `Digest`, а не `docs/` отдельно).
2. В настройках репозитория откройте **Settings → Pages**.
3. В **Source** выберите ветку `main` и папку `/docs`.
4. Сайт появится по адресу `https://<username>.github.io/<repo>/` через пару минут.

Дополнительных файлов конфигурации не требуется — это обычные статические файлы.

Mobile app as a strategic priority

2025–2026

Task

The mobile app had long lagged behind mobile web on key metrics. We needed to build systematic work on the funnel and UX quality to make the app a priority channel.

Role

  • Hired designers specializing in mobile
  • Moved from a separate mobile team to a model where every team's designer handles both web and app tasks
  • Introduced a cross-platform approach: a unified visual language and a shared UI kit

Cross-platform design

Designers worked on web and mobile in parallel, but the UI kits existed separately — tokens and components duplicated and drifted apart. So I:

  • Initiated an audit of the discrepancies
  • Made the architectural decision to unify them with theme support
  • Built an update process together with developers
  • Organized training sessions for the team

Result

  • The mobile app overtook mobile web on all key metrics — driven by UX quality, not just marketing;
  • Reduced the number of component and token variations between platforms;
  • Each team ships features for web and app — without increasing designer headcount costs;
  • Built sustainable processes for working with a unified design system.

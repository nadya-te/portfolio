UX strategy for the teacher dashboard

2025

Task

The teacher dashboard grew organically — without a unified UX strategy. Every team added its own sections and widgets. Teachers couldn't find the tools they needed, and new features didn't move engagement.

From a UX standpoint, the task was to build a scalable architecture of services and a hub page — not a set of disconnected blocks and banners, as it had been before.

Key business metrics: growth in homework-assignment conversion and growth in teacher activity.

Role

  • Initiated an audit: in-depth interviews with teachers, analysis of current section traffic to identify priority scenarios
  • Defined a new UX strategy based on research and business requests
  • Broke the changes down into a concrete, sequenced set of hypotheses
  • Rolled out the new version in stages together with the product team

Hypotheses

Four key UX and design problems were identified in the current product. A hypothesis was formulated for each.

Before the redesign

Problem: widgets on the dashboard duplicate the left-hand menu without adding useful information.

Hypothesis: surface key widgets and give teachers a faster, simpler path to useful actions.

Problem: long paths to actions when navigating sections (sidebar → section → subsection).

Hypothesis: reduce the number of navigation elements and structure them around the teacher's CJM.

Problem: no priorities or a clear system of triggers and rewards.

Hypothesis: create a dynamic task system, visually gathered in one place.

Problem: current events (marathon, olympiad, quiz) are mixed in with the rest of the content.

Hypothesis: surface what's currently active as a separate block.

Мобильное приложение как стратегический приоритет

2025–2026

Задача

Мобильное приложение долгое время уступало мобильному вебу по ключевым метрикам. Нужно было выстроить системную работу с воронкой и качеством UX, чтобы приложение стало приоритетным каналом.

Роль

  • Наняла дизайнеров со специализацией на мобайле
  • Перешли от отдельной мобильной команды к тому, что в каждой команде дизайнер делает задачи и для веба, и для приложения
  • Ввела кросс-платформенный подход: единый визуальный язык и общий UI-кит

Кросс-платформенный дизайн

Дизайнеры работали параллельно над вебом и мобайлом, но UI-киты существовали отдельно — токены и компоненты дублировались и расходились. Поэтому я:

  • Инициировала аудит расхождений
  • Приняла архитектурное решение об объединении с поддержкой тем
  • Выстроила процесс обновления с разработчиками
  • Организовала обучающие сессии для команды

Результат

  • Мобильное приложение обогнало мобильный веб по всем ключевым метрикам — за счёт качества UX, а не только маркетинга;
  • Сокращено количество вариаций компонентов и токенов между платформами;
  • Каждая команда закрывает фичи для web и app — не увеличив ФОТ дизайнеров;
  • Выстроены устойчивые процессы работы с единой дизайн-системой.
